# Minor Project Lab Report: Automated Plant Watering

## Introduction
This project automates plant watering using **Java** and **Arduino**.  
A soil moisture sensor monitors the soil's water level and starts or stops the water flow accordingly. This allows plants to be watered automatically based on their moisture needs.

---

## Technical Requirements / Specifications
- The soil moisture sensor detects soil moisture.
- If the soil is dry, the water pump turns on.
- If the soil is sufficiently moist, the pump stays off.

---

## Components List
- Arduino board
- Soil moisture sensor
- MOSFET driver
- Water pump
- Red LED
- Push button
- Display (U8x8 library compatible)
